# 🎬 Netflix Movies & TV Shows - Exploratory Data Analysis

## 📌 Project Overview
This Data Science Mini Project analyzes the Netflix Movies and TV Shows dataset to uncover content distribution patterns, geographical production trends, release timelines, and audience rating preferences.

## 🎯 Key Objectives
- Clean and preprocess real-world messy data (handling missing values and date formats).
- Perform Exploratory Data Analysis (EDA) using Python.
- Build a multi-chart visualization dashboard to communicate actionable insights.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Environment:** VS Code / Jupyter Notebook

## 📊 Key Findings & Insights
1. **Movies Dominate the Catalog:** Movies make up roughly **~69%** of the total content library compared to **~31%** TV Shows.
2. **Top Content Producers:** The **United States** leads global content production by a wide margin, followed by India and the United Kingdom.
3. **Rapid Growth Post-2015:** Content releases saw exponential growth between 2015 and 2019.
4. **Target Audience:** **TV-MA** (Mature Audiences) and **TV-14** are the most prevalent content ratings on the platform.
